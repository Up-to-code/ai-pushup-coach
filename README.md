# AI Pushup Coach

Expo application and companion web interface for an AI pushup coaching project.

[Source](https://github.com/Up-to-code/ai-pushup-coach) · [Issues](https://github.com/Up-to-code/ai-pushup-coach/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

Next.js, Expo, React Native, React, TypeScript, Convex.

## Get started

```sh
git clone https://github.com/Up-to-code/ai-pushup-coach.git
cd ai-pushup-coach
```

Requires Node.js and npm.

```sh
npm ci
npm run start
```

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run start` | Start the configured application |
| `npm run test` | Run the configured tests |
| `npm run check` | Run project checks |
| `npm run typecheck` | Check types |
| `npm run android` | Run the Android workflow |
| `npm run ios` | Run the iOS workflow |
| `npm run web` | Run the web workflow |
