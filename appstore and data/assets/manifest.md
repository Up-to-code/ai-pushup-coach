# Push Counter Asset Manifest

These files are copied from the app repo so the website and App Store preparation bundle can be uploaded as a self-contained package.

## Files

| Bundle file | Source path | Purpose |
| --- | --- | --- |
| `icon.png` | `assets/icon.png` | Main app icon, app page icon, and App Store icon source. |
| `adaptive-icon.png` | `assets/adaptive-icon.png` | Android adaptive foreground and backup icon source. |
| `favicon.png` | `assets/favicon.png` | Website favicon. |
| `splash-icon.png` | `assets/splash-icon.png` | Splash and logo artwork source. |
| `logo-push-up.png` | `assets/brand/logo-push-up.png` | Brand logo for website sections and developer card visuals. |
| `home_bg.png` | `assets/images/home_bg.png` | Home or hero visual for the landing page. |
| `onboarding_camera.png` | `assets/images/onboarding_camera.png` | Camera-assisted tracking visual. |
| `onboarding_compete.png` | `assets/images/onboarding_compete.png` | Challenges, leaderboard, or competition visual. |

## Upload Guidance

- Use `icon.png` for the app card icon on Nexfiy and as the App Store icon source.
- Use `favicon.png` only for browser favicon contexts.
- Use `home_bg.png`, `onboarding_camera.png`, and `onboarding_compete.png` as website visuals or supporting app-page media.
- Use Apple's official App Store badge from Apple marketing tools instead of recreating it from app assets.
- Keep all public copy aligned with the Push Counter name and the `https://nexfiy.com/apps/push-counter` URL set.
