# Website Format Notes

Use `landing-page.md` as the content source for the Push Counter website format shown in the reference screenshot.

## Page Structure

Use this order:

1. Header navigation.
2. Breadcrumb row.
3. App hero with app icon, title, category, and CTA buttons.
4. Store stats row.
5. Overview section.
6. Features table or rounded feature card.
7. Developer support card.
8. Footer legal links.

## Header

Left brand: Nexfiy

Centered navigation:

- Home
- Apps
- Services
- Contact

Right button:

- Get Started

## Breadcrumb

Home > Apps > Push Counter

Keep Push Counter as the final active breadcrumb label.

## Hero

Use `assets/icon.png` as the app icon. Place it in a white rounded icon card similar to the screenshot.

Hero text:

- Title: Push Counter
- Category: Health & Fitness

Buttons:

- GET: link to the App Store product page after launch.
- ANDROID COMING SOON: disabled or informational until a Play Store listing is live.
- WEB: link to https://pushcounter.online or a web preview if one exists.

## Store Stats

Use a three-column stat row:

- `4.9 star` with label `New app`
- `Launching soon` with label `Downloads`
- `v1.0.0` with label `Version`

Do not claim real downloads or ratings until App Store data exists.

## Features

Use the feature rows from `landing-page.md`. The visual pattern should match the screenshot: feature name on the left, short description on the right, with light dividers.

## Developer Card

Use this copy:

Push Counter is designed and built by Nexfiy for calm, focused fitness tracking. The app is meant to support consistent training without turning every workout into noise.

## Apple Review Safety

Keep website copy consistent with the App Store listing. Do not add claims about medical advice, guaranteed fitness outcomes, exact camera accuracy, saved videos, Android availability, or real ratings/downloads unless the app and store listing support those claims.
